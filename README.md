# Portfolio 2026

React + Vite + TypeScript. The splash animates **Hello World! → Hello Simulation! → Hello World!**, then reveals a placeholder homepage introducing Shakaib Khan.

## Live website

**[Open Portfolio 2026](https://shakaib732.github.io/portfolio-2026/)**

The site is deployed through the GitHub Actions workflow in `.github/workflows/deploy.yml`. GitHub Pages must use **GitHub Actions** as its build and deployment source in repository Settings → Pages.

## Local development

```bash
npm install
npm run dev
npm run build
```

Vite's base path is `/portfolio-2026/`.
